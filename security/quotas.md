# Budget, cost and quota gates
Pilot: set tenant API gateway rate caps, per-model concurrency limits, token request budgets, maximum prompt length and per-tool authorization quotas before accepting real users. POC metric lsk_llm_tokens_total reads provider usage, but does not bill costs. Verified cost reporting requires dated model SKU prices and accounting for input/output/cached tokens; vLLM spend requires node hourly cost, GPU utilization, storage and network egress. Alert before daily and monthly budget thresholds; hard-fail or route to human escalation when exceeded. Quotas are DESIGN ONLY, not enforced by present runtime.
