# FDE workshop and adoption
Workshop 1: stakeholder process mapping, legacy tickets and approvals.
Workshop 2: select inference residency, identity integration, network access and role/tenant architecture.
Workshop 3: install POC, run real-model evaluation, observe errors and traces, demonstrate denied identities.
Workshop 4: cost/latency review, threat modeling, on-call troubleshooting, approval for pilot expansion.
Adoption KPIs: weekly active developer teams; deployment-request lead time; approved agent deployment count; grounded answer acceptance; escalations to human support; cost per successful task; time to remediate.
Escalation tiers: L1 customer service desk, L2 platform SRE, L3 model/identity engineer, P1 customer security contact. Record incident ID, timestamps, sanitized trace ID, model version, incident severity, mitigations and handoff.
