# FDE customer discovery
1. Which B2B personas and existing ticket/deploy processes are authoritative?
2. Where are confidential agreements stored and who grants access?
3. Which customer tenant owns each document and application?
4. Data residency: hosted API permitted, self-hosted GPU available, egress restrictions?
5. Existing IdP, groups, OIDC issuer, user delegation, service identities?
6. Required retention, deletion, audit export, privacy and DLP controls?
7. Target RPS, p95 latency, workload peaks, token and GPU budget?
8. Customer security review and change approval contacts?
9. What is the escalation path for unsupported or unsafe agent actions?
10. What constitutes pilot adoption, task completion and business success?
